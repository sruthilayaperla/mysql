# MySQL Data Analysis

A collection of SQL and data-analysis material, including a Walmart sales case study and a Swiggy dataset.

## Contents
- `Walmart sales/` — Walmart sales CSV, MySQL dump, and project documentation.
- `casestudy-swiggy/` — Swiggy CSV dataset.

## Walmart Sales
The project documentation covers product, sales, customer, branch/city, payment, time, rating, COGS, VAT, gross income, and margin analysis. The SQL dump defines a `sales` table and includes derived time fields.

## Technologies
MySQL, SQL, CSV, exploratory and business-oriented data analysis.

## Getting Started
Open `Walmart sales/walmartsales_backup.sql` in MySQL to recreate the stored `sales` table and data. The dump was exported from MySQL 8.0.46.

## Notes
The Swiggy folder currently contains the dataset itself; no separate analysis script is present there.
